Job Description

We are seeking an AI-Native Software Engineer to help transform our software development process into an AI-first engineering model. In this role, you will use AI tools as a primary development partner to convert requirements into working software solutions faster, while maintaining strong responsibility for quality, correctness, security, and production readiness. 

You will be expected to take business and technical requirements, create precise prompts and implementation plans, generate a significant portion of the initial solution using AI, and then carefully validate the output for hallucinations, prompt accuracy, missing logic, incorrect assumptions, and alignment with expected outcomes. The goal is not simply to generate code quickly, but to deliver reliable, maintainable, and well-tested software using AI as an accelerator. 

The ideal candidate is a strong software engineer with hands-on experience using AI tools for coding, design, testing, documentation, debugging, and refactoring. You should be comfortable working with ambiguity, breaking down requirements into AI-executable tasks, reviewing AI-generated code, and taking full ownership of the final solution. 

Responsibilities 

 

  • Use AI-assisted development tools to generate, test, document, refactor, and improve software solutions. 

  • Convert product and business requirements into clear technical prompts, implementation plans, and acceptance criteria. 

  • Generate 80–90% of initial solution drafts using AI tools, then review, validate, and refine the output. 

  • Detect and correct AI hallucinations, inaccurate assumptions, invalid code, security issues, and gaps in requirements. 

  • Create automated tests to verify expected behavior and business outcomes. 

  • Ensure all AI-generated code meets company standards for architecture, security, maintainability, performance, and documentation. 

  • Build reusable prompt templates and AI-native development workflows for common engineering tasks. 

  • Collaborate with product, QA, DevOps, architecture, and security teams to deliver production-ready solutions. 

  • Document prompts, assumptions, validation steps, risks, and final implementation decisions. 

  • Help educate and guide other engineers in adopting AI-native software development practices. 

 

 

Requirements 

 

  • Strong software engineering background with experience building production-grade applications. 

  • Proficiency in one or more modern programming languages. 

  • Experience using AI coding tools or large language models for software development. 

  • Strong understanding of APIs, databases, cloud services, testing, CI/CD, and secure coding practices. 

  • Ability to write precise prompts and evaluate AI-generated outputs critically. 

  • Strong debugging, testing, code review, and problem-solving skills. 

  • Ability to identify hallucinations, incorrect logic, missing edge cases, and gaps between generated code and requirements. 

  • Excellent communication and documentation skills. 

  • Strong sense of ownership for final deliverables, regardless of whether the initial code was AI-generated. 

 

 

Preferred Experience 

 

  • Experience with GitHub Copilot, Cursor, ChatGPT, Claude, Gemini, Amazon Q Developer, or similar tools. 

  • Experience creating prompt libraries, AI development workflows, or internal engineering automation. 

  • Experience with LLM applications, AI agents, retrieval-augmented generation, or workflow orchestration. 

  • Experience leading process transformation or helping engineering teams adopt new development practices. 

  • Knowledge of AI governance, data privacy, security, and responsible AI usage. 

What We Expect From This Role 

This role is designed for an engineer who can operate in a future-facing development model. You will not only write code; you will design the way software is created with AI. You will be responsible for accelerating delivery while ensuring that every final output is correct, tested, secure, and aligned with business expectations.
