The Role
Develop enterprise .NET and C# applications, APIs, microservices, and event-driven architectures on Azure. Integrate Azure OpenAI, Cognitive Services, Azure ML, and AI Foundry to deliver semantic search, document intelligence, chatbots, and recommendation features. About the opportunity
We are hiring on behalf of a well-established global IT consulting and implementation firm with a decade-long track record, offices across North America, Europe, and India (HITEC City, Hyderabad). The organisation helps enterprises modernise business systems through SAP, Azure, AI, and Cloud technologies and has a strong people-first culture.

Role overview
We are looking for an Azure & .NET Engineer with emerging AI capabilities to join the Engineering Practice in Hyderabad. This is a hands-on role for an experienced .NET/C# developer who wants to build real AI-powered products — integrating Azure OpenAI, Cognitive Services, and machine learning pipelines into enterprise-grade applications for global clients.

Key responsibilities
• Design and develop enterprise applications and APIs on .NET (C#) deployed on Microsoft Azure
• Integrate Azure AI services — Azure OpenAI (GPT-4 / embeddings), Cognitive Services, and Azure ML — into live application workflows
• Build intelligent features: semantic search, document intelligence, chatbot interfaces, and recommendation engines using Azure AI Foundry
• Develop RESTful APIs, microservices, and event-driven architectures using Azure Service Bus, Event Grid, and Azure Functions
• Collaborate with data engineers to build pipelines that surface AI/ML insights within .NET applications
• Ensure code quality through unit testing, code reviews, and SOLID principles
• Participate in architecture discussions and contribute to technical design documentation

Required skills & experience
• 8+ years in software development with strong C# / .NET Core or Framework proficiency
• Solid Azure platform experience: App Services, Azure Functions, Azure SQL, Cosmos DB, Service Bus
• Hands-on integration of at least one Azure AI service in production (OpenAI, Cognitive Services, Form Recognizer, etc.)
• Understanding of prompt engineering, RAG (Retrieval Augmented Generation) patterns, and vector databases (Azure AI Search or Pinecone)
• Experience with Git and CI/CD pipelines (Azure DevOps or GitHub Actions)
• Agile/Scrum environment experience

Good to have
• Microsoft Certified: Azure Developer Associate (AZ-204)
• Exposure to Python for ML scripts or AI model fine-tuning
• Familiarity with Semantic Kernel, LangChain, or AutoGen frameworks
• Understanding of responsible AI practices and model governance

What's on offer
• Early-mover advantage on cutting-edge Azure AI stack projects
• Certification reimbursement and structured learning pathways
• Hybrid work flexibility from HITEC City, Hyderabad
• Direct exposure to global clients across North America, UK, and APAC

Location: Hyderabad (Hybrid / On-site)
Experience: 8+ years
