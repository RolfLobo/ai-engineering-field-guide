Experience: 10+ Years
Role Overview

We are looking for an experienced Senior Full Stack Java Developer with 10+ years of software development experience and strong exposure to Agentic AI, Generative AI, and AI-assisted software development.

The ideal candidate should have deep hands-on expertise in Java, Spring Boot, Microservices, REST APIs, modern frontend frameworks such as React or Angular, databases, cloud technologies, and CI/CD, along with practical experience using AI agents and AI coding tools to accelerate software development, testing, debugging, and engineering workflows.

The candidate will work across backend, frontend, architecture, integrations, and AI-assisted development to build scalable, secure, and production-grade enterprise applications.

Key Responsibilities
  • Design and develop scalable full-stack applications using Java and Spring Boot.
  • Build and maintain Microservices and REST APIs for enterprise applications.
  • Develop responsive frontend applications using React.js or Angular.
  • Design scalable application architecture and participate in system design discussions.
  • Integrate applications with databases, APIs, messaging platforms, and external systems.
  • Use Agentic AI and AI-driven coding approaches to improve development productivity and software quality.
  • Build or integrate AI agents, LLM-powered workflows, and tool-calling capabilities where required.
  • Use AI coding tools for code generation, refactoring, debugging, testing, and documentation.
  • Develop reusable backend and frontend components.
  • Implement secure authentication and authorization using technologies such as OAuth2, JWT, and Spring Security.
  • Work with relational and NoSQL databases.
  • Build event-driven solutions using Kafka or similar messaging technologies.
  • Implement unit, integration, API, and frontend testing.
  • Participate in code reviews and enforce software engineering best practices.
  • Develop and maintain CI/CD pipelines.
  • Work with Docker, Kubernetes, and cloud platforms.
  • Troubleshoot complex production issues and perform root-cause analysis.
  • Collaborate with architects, product teams, DevOps, QA, and AI engineering teams.
  • Mentor junior and mid-level developers and provide technical guidance.
