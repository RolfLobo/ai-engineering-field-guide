# Use Cases

Keyword-classified themes over the use-case text extracted from 6,964 postings (6,889 have at least one use case). Classification is keyword matching over the extracted use-case sentences, so one posting can carry several themes and borderline phrasings are missed - treat this as an approximate view; the exact sentences live in the [dataset](../../job-market/data_structured/).
